# Генератор изображений по описанию

Программа создаёт картинки из текста прямо на вашем компьютере, без интернета и подписок
(интернет нужен только чтобы один раз скачать модель и переводить русский текст).
Используются бесплатные библиотеки: **PyTorch**, **Diffusers** (Stable Diffusion), **Gradio**.

Настроено под **GTX 1660 Super (6 ГБ) + 16 ГБ ОЗУ**:
- модель работает в float32: у карт GTX 16xx режим float16 даёт чёрные картинки;
- включена экономия видеопамяти (attention/VAE slicing);
- если видеопамяти не хватит, часть модели сама переедет в ОЗУ.

## Установка (Windows)

1. Установите **Python 3.10–3.12** с https://www.python.org/downloads/
   и при установке отметьте **«Add Python to PATH»**.
2. Обновите драйвер NVIDIA.
3. Дважды щёлкните **`install.bat`** и дождитесь конца установки (скачается около 3 ГБ).
   В конце должно появиться `CUDA доступна: True - NVIDIA GeForce GTX 1660 SUPER`.

## Запуск

Дважды щёлкните **`run.bat`**. Откроется браузер с адресом http://127.0.0.1:7860.
Напишите описание (можно по-русски) и нажмите «Сгенерировать».

При первой генерации модель скачивается (2–4 ГБ), это займёт несколько минут.
Все картинки сохраняются в папку `outputs`.

## Модели

| Модель | Для чего | Время на 1660 Super (512×512) |
|---|---|---|
| DreamShaper 8 (по умолчанию) | красивые картинки в любом стиле | ~15–25 с |
| Stable Diffusion 1.5 | оригинальная базовая модель | ~15–25 с |
| SD-Turbo | черновики, 1–4 шага | ~2–4 с |

## Советы

- Лучший размер — **512×512** (модели обучены на нём). 512×768 тоже подходит для портретов.
- Добавляйте детали: стиль, освещение, ракурс. Например:
  «портрет рыжей кошки в очках, масляная живопись, мягкий свет, высокая детализация».
- Понравилась картинка — запишите её **Seed** и введите его снова, чтобы менять описание,
  сохраняя композицию.
- «Шаги»: 20–30 — хороший баланс. «CFG»: 6–8 — обычно лучший вариант.

## Командная строка

```
venv\Scripts\activate
python generator.py "замок в горах на закате, фэнтези" -n 4
python generator.py "a cozy cabin in snowy forest" --model turbo --seed 42
python generator.py --help
```
