во взрослую женщину по референсу из `characters/woman_meshy/reference`.

```
cd C:\blender\blender\characters\woman_from_chibi
python woman_from_chibi.py --glb C:\Users\New\Downloads\Meshy_AI_Chibi_Figure_0926172701_texture.glb --out out
```

В `out/`: `woman_from_chibi.blend`, снимки спереди / 3/4 / сбоку / сзади / лицо, `sheet.jpg`.
