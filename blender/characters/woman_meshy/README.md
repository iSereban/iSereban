# Женщина из Meshy — раскраска по референсу

`woman_meshy.py` красит модель женщины из Meshy без цвета по картинке `reference/front.jpg`:
спереди — проекция картинки (совмещение по силуэту: макушка, шея, стопы, центр тела; голова —
отдельно), сзади и по бокам — цвета зон, снятые с той же картинки (волосы с сединой, пыльно-розовый
кардиган, кремовая блузка, бежевые брюки, молочные носки, кожа).

- `reference/` — референсы (front — в полный рост спереди, side, face, pose34)
- `test_standin/` — проверка на заменяющей модели без цвета (у неё другая голова, поэтому лицо
  совпадёт только на настоящей модели, сделанной по этой картинке)

Запуск: `python woman_meshy.py --glb "C:\Users\New\Downloads\woman.glb" --out out`
или в Blender: указать `GLB_PATH` и Run Script. Функция `load_painted(glb)` — для роликов.
Если сдвинуто лицо — поправка в `reference/front_align.json` (`{"cx": …, "top": …, "neck": …}` в пикселях).
