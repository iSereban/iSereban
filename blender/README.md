# Blender-студия: персонажи, объекты, локации, ролики

Всё строится Python-скриптами по координатам/чертежам. Папка = `C:\blender\...` у тебя после клонирования.

```
blender/
├── common/studio.py        общие утилиты: очистка сцены, материалы, свет, камеры, рендер 480p, mp4
├── characters/             (будущие персонажи)
├── sapsan/                 поезд «Сапсан» + ролик
├── objects/                (будущие объекты)
├── locations/              (будущие локации)
└── scenes/                 (будущие ролики по сценариям)
```

## Правила проекта

- **Единицы:** метры, Z вверх, пол Z=0. Персонажи смотрят в −Y.
- **Качество:** рендер 854×480 (`studio.RES_480`), 25 fps, Cycles 16 samples — быстро и дёшево.
  Для финала потом поднимем разрешение одной строкой.
- **Цвета в скриптах — линейные** (как в поле Blender), не sRGB.
- Каждый элемент имеет функцию `build(...)`, чтобы собирать сцены из нескольких персонажей/локаций.
- Видео: скрипты пишут MP4 (H.264) в `render/` рядом с .blend.
