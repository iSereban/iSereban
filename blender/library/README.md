# Библиотека объектов (по координатам и чертежам)

Каждый объект — **отдельная спецификация в координатах** (мм): список деталей
(`box`/`cyl`/`cone`/`sph`/`text`) с размерами, положением, поворотом и материалом.
Из одной и той же спецификации получаются:

| Что | Где |
|---|---|
| 3D-модель | `parts.build_mesh(spec)` / `parts.place(spec, location, rot)` |
| Чертёж: 3 вида + размеры + штамп | `out/drawings/<код>.png` (`python drawings.py`) |
| Превью 854×480 | `out/previews/<код>.jpg` (`python render_library.py`) |
| Все объекты в одном файле (ассеты) | `out/furniture_library.blend`, `out/city_library.blend` |

Начало координат объекта — центр основания на полу, фасад смотрит в **−Y**, Z — вверх.
Настенные/потолочные (часы, картины, шторы, люстры) — от точки крепления.

## Файлы
- `catalog_furniture.py` — мебель и быт квартиры (диван, стенка с сервизом, кресло, трюмо, кровать,
  шкаф, швейная машинка «Чайка», книжный шкаф, кухонный гарнитур, холодильник, стол со скатертью,
  табуреты, чайник, окна, двери, батареи, ванна, раковина, унитаз, стиралка, ковры, фикус, фиалки…)
- `catalog_city.py` — город (пятиэтажка, девятиэтажка, «Продукты», «Аптека», кафе «Уют», «Хлеб»,
  киоск, остановка, фонарь, светофор, липа, берёза, скамейка, урна, 4 машины)
- `palette.py` — материалы (цвета линейные), `parts.py` — сборка в Blender, `drawings.py` — чертежи.

## Как добавить объект
Написать функцию в каталоге, вернуть `spec(name, title, group, parts)`, добавить в `CATALOG`,
затем `python drawings.py --only <код>` и `python render_library.py --only <код>`.
