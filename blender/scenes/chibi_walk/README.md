# Тест: сгенерированный персонаж (Meshy/Tripo .glb) — ролик 15 с, 480p

Скрипт `chibi_walk.py` берёт любую модель человека/чиби в `.glb` (без рига), сам строит скелет
(`blender/common/autorig.py`) и снимает сцену:

| Кадры | Время | Действие | Камера |
|---|---|---|---|
| 1–100 | 0–4 с | идёт к камере | наезд спереди, камера пятится |
| 101–150 | 4–6 с | приседает и встаёт | профиль |
| 151–200 | 6–8 с | идёт | ноги крупно у земли, камера едет рядом |
| 201–250 | 8–10 с | идёт | кран сверху-сзади, опускается |
| 251–295 | 10–11,8 с | разворачивается на 180° | общий план |
| 296–335 | 11,8–13,4 с | прыгает от радости, руки вверх | нижний «героический» ракурс |
| 336–375 | 13,4–15 с | машет рукой в камеру | наезд |

## Запуск у себя

1. `git pull` в папке проекта.
2. В начале `chibi_walk.py` проверь путь: `GLB_PATH = r"C:\Users\New\Downloads\Meshy_AI_Chibi_Figure_0926172701_texture.glb"`.
3. Blender → **Scripting** → **Open** → `blender\scenes\chibi_walk\chibi_walk.py` → **Run Script** (▶).
   Сцена соберётся за 10–60 с.
4. **File → Save As** (например `C:\blender\chibi_walk.blend`) — чтобы видео легло рядом.
5. **Render → Render Animation** (Ctrl+F12). Результат: `render\chibi_walk_0001-0375.mp4`.

Если персонаж стоит спиной к камере — `TURN = 180.0`; если слишком большой/маленький — `HEIGHT`.

Из командной строки:
```
blender -b -P chibi_walk.py -- --glb "C:\Users\New\Downloads\model.glb" --out out --render
```
