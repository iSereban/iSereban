# Город (сцена по координатам)

`city.py` собирает город из объектов библиотеки по таблице `LAYOUT` (метры, поворот):
перекрёсток двух улиц (проезжая часть 7 м, тротуары 3 м с бордюрами, осевая разметка, зебры,
стоп-линии), пятиэтажки №1 и №2, девятиэтажка, «Продукты», «Хлеб», киоск, «Аптека», кафе «Уют»,
остановка, фонари, светофоры, сквер с липами/берёзами и скамейками, машины на полосах.

- `out/city.blend` — сцена (камеры `shot_*` уже расставлены)
- `out/city_plan.png` — генплан с подписями, координаты в мм
- `out/shot_*.jpg` — скриншоты 854×480

Запуск: `python city.py` (bpy) или Blender → Scripting → Run Script.
