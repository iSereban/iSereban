# Квартира: 3 комнаты + кухня (хозяйка 50+)

`apartment.py`: план в координатах (`ROOMS`, `WALLS` с проёмами), расстановка мебели (`FURNITURE`),
камеры (`CAMERAS`). Всё в мм, потолок 2700, наружные стены 300, перегородки 120.

| Помещение | Размер | Что стоит |
|---|---|---|
| Гостиная | 4,8×4,2 м (20,2 м²) | стенка с сервизом и ТВ, диван, кресло, столик с вазой и чайным сервизом, ковёр, торшер, фикус, люстра, часы, картина, шторы, фиалки на подоконнике |
| Спальня | 3,6×4,2 м (15,1 м²) | кровать 160×200, 2 тумбочки с лампами, шкаф с зеркалом, трюмо, пуф, ковёр, люстра, картина |
| Кухня | 3,2×4,2 м (13,4 м²) | гарнитур 3 м (мойка, плита с духовкой, вытяжка), холодильник, микроволновка, чайник, стол со скатертью и сервизом, 3 табурета, часы |
| Комната 3 | 3,6×3,0 м (10,8 м²) | диван-книжка, письменный стол со швейной машинкой «Чайка», стул, книжный шкаф, кресло, фикус |
| Прихожая | 6,0×3,0 м | входная дверь, шкаф-прихожая с вешалкой и зеркалом, коврик |
| Ванная | 2,0×3,0 м | ванна, раковина с зеркальным шкафчиком, унитаз, стиральная машина, плитка |

Файлы (`out/`):
- `apartment.blend` — вся квартира; `room_<комната>.blend` — отдельный файл каждой комнаты
- `apartment_plan.png` — план с мебелью, площадями и размерами
- `overview_*.jpg` — «кукольный домик» (без потолка), `<комната>_*.jpg` — скриншоты из комнат
