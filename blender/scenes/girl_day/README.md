# «День девочки» — ролик 1 минута (480p, 25 к/с)

Персонаж — чиби-девочка из Meshy (`Meshy_AI_Chibi_Figure_0926172701_texture.glb`), скелет — `common/autorig.py`,
суставы — `scenes/chibi_walk/…joints.json`, рост в ролике 1,3 м.

| Часть | Кадры | Что происходит |
|---|---|---|
| Комната (`room.py`) | 1–900 | пишет в тетради → кладёт карандаш, закрывает тетрадь → отодвигает стул, встаёт → идёт к комоду, расчёсывается у зеркала → звонит телефон, смотрит, радуется → телефон в карман → поднимает рюкзак, закидывает на спину → уходит в дверь |
| Улица (`street.py`) | 1–600 | выходит из подъезда пятиэтажки №1, спускается с крыльца → идёт по тротуару, оглядывается → камера-кран за спиной |

Файлы:
- `performer.py` — анимация: путь (Hold/Walk), позы (сидеть, присесть, подпрыгнуть, наклон, взгляд), IK рук, реквизит (в мире / в руке / на спине)
- `cinema.py` — планы камеры: движение, сглаженная цель, фокус, «дикие» стены, **проверка перекрытий** (`--check`)
- предметы детской и реквизит (расчёска, телефон, рюкзак, тетрадь, карандаш…) — `library/catalog_girl.py`, чертежи в `library/out/drawings/`

```
python girl_day.py --part room   --glb <девочка.glb> --out out --check          # проверка камер
python girl_day.py --part room   --glb <девочка.glb> --out out --render         # кадры 1–900
python girl_day.py --part street --glb <девочка.glb> --out out --render         # кадры 1–600
python girl_day.py --join --out out                                             # → out/girl_day.mp4
```
**На своём ПК (видеокарта):** двойной щелчок по `render_girl_day.bat` — рендерит обе части на GPU (`--gpu`),
потом склеивает их средствами Blender в `out\girl_day_0001-1500.mp4`. Рендер можно прервать и запустить снова —
готовые кадры пропускаются.
